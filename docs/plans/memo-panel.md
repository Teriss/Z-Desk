# Z-Desk 多便笺列表与详情改造

## 背景与目标

将现有单一连续文档改为类似 Microsoft 便笺的多笔记结构，仍只使用一个置顶窗口。快捷键打开笔记列表，点击卡片进入详情编辑；富文本、链接、代码、RTF/HTML、图片粘贴和本地持久化能力继续保留。

## 范围与非目标

- 范围：列表缩略卡片、详情编辑、新建/搜索/删除、单窗口导航、索引与逐笔正文存储、旧单文档迁移、损坏恢复和文档更新。
- 非目标：每条笔记独立窗口、颜色/标签/置顶、回收区/撤销删除、OCR、云同步、远程图片下载。

## 默认值与风险

- 快捷键唤出时总是显示列表；首次无笔记时显示空状态和新建按钮；新建立即进入空白详情。
- 首行自动作为标题，正文生成摘要和完整纯文本搜索缓存；第一张图片生成约 `336×216` 缩略图。
- 删除确认后永久删除；旧单文档自动迁移为第一条笔记并将旧文件归档为 `.legacy`。
- 正文与图片只在备忘录目录保存，不进入布局、日志或诊断包；WPF XAML Package 序列化和大图处理仍需关注 UI 线程工作集。
