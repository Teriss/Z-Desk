# 二维码区域识别功能

## 背景与目标

为 Z-Desk 增加本地二维码区域识别：用户录制全局快捷键后打开 ScreenToGif 式可移动、可缩放取景框，点击识别时读取框内区域，识别其中全部二维码并复制结果。进入取景框不捕获桌面；图像和识别内容只在内存中短暂存在。

## 范围与非目标

- 范围：可配置快捷键、跨屏取景框、多二维码解码、深色结果窗口、取景框边界持久化、文档和验证。
- 非目标：条形码识别、图片文件导入、识别历史、自动打开链接或联网解析。

## 风险或待确认事项

- UAC 安全桌面、DRM 或硬件保护画面可能不能由 GDI 捕获。
- 超大取景区域在点击识别时仍需要短时内存；进入取景框本身不读取屏幕，识别在后台线程执行，避免阻塞交互。
- 取景框必须在实际 Windows 多显示器环境验证鼠标穿透、焦点、八向缩放和混合 DPI 坐标；自动测试只能覆盖几何和视觉树状态。
- 2026-08-04 回归：现有右键在按下时关闭覆盖层，导致右键抬起可能传给背后窗口；逐显示器截图在双 2560x1440 屏幕上暖机约 145-170 ms，且当前 ZXing.Net 未能识别渐变、圆点和中心 Logo 风格二维码。
