# Z-Desk Win10 兼容、规则、快捷键与贴边隐藏改造

## 总结

- 使用矢量路径替代系统图标字体，保证 Win10/Win11 显示一致。
- 简化规则类型配置，增加快捷方式目标路径匹配。
- 将单一置顶快捷键改为可配置的快捷键列表。
- 增加“QQ 式贴边隐藏”模式，与现有标准模式切换。
- 升级配置模型并自动迁移现有用户数据。

## 实现改动

### Win10 图标兼容

- 将布局标题栏的打开、折叠/展开、锁定/解锁图标全部改为 WPF `Path/Geometry`，不再依赖 `Segoe Fluent Icons`。
- 设置窗口最小化、关闭等自定义字形一并改为矢量图标，避免其他 Win10 字体缺失问题。
- 保持现有按钮尺寸、悬停和按下效果。

### 自动归类规则

- 删除规则表格中的“仅目录/仅应用”列。
- 目录预设在模型内部保留目录限定；应用通过 `.exe;.lnk;.url` 扩展名自动识别，其他带扩展名的规则自动限定为文件。
- 新增“路径关键词”字段：多个关键词使用分号分隔，字段内部为 OR；扩展名和路径字段之间为 AND；匹配不区分大小写；空字段表示不限制。
- 路径候选包括桌面项目完整路径、`.lnk` 目标和启动参数、`.url` 的 URL；解析失败时回退到项目自身路径，不中断归类。
- 示例游戏规则：扩展名 `.exe;.lnk;.url`，路径关键词 `steam;steamapps;epic;gog;riot;ubisoft;ea app;battle.net`。

### 自定义置顶快捷键

- 快捷键设置改为列表，支持新增、删除、启用、录制组合键和多选目标布局。
- 每条配置包含快捷键、全部布局选项或显式目标布局 ID 列表。
- 快捷键按一次开启所选布局置顶，再按一次关闭；显式选中组合布局子页签时自动切到目标页。
- 多条快捷键按目标集合并集管理置顶状态；配置应用时原子替换快捷键注册。

### QQ 式贴边隐藏

- 设置中增加标准模式和贴边隐藏模式。
- 新模式支持左、右、上边缘；布局离开后移出屏幕，仅保留约 3px 感应区域。
- 鼠标进入感应区域时展开并在悬停期间置顶，离开后收回并恢复桌面底层。
- 菜单、拖放、缩放、重命名等交互期间暂停收回；快捷键置顶时保持展开。
- 保留跨显示器拖动；仅程序控制的贴边隐藏允许移出屏幕，用户拖动仍受边界限制。

## 数据模型与迁移

- 新增 `TopmostHotKeyBinding`、`LayoutInteractionMode`、`DockEdge` 和 `LayoutMatchRule.PathContains`。
- 旧 `TopmostHotKey` 自动迁移为一条“全部布局”快捷键配置，活动状态不跨重启保存。
- 停靠边、布局位置、快捷键目标和规则路径条件持久化；组合/拆分页签使用稳定布局 ID。
- 更新 README 和架构文档，标明 Win10 22H2 x64 / Win11 支持情况及新配置语义。
