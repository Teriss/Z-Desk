# 隐私说明

Z-Desk 默认仅在本机处理数据，不上传文件、文件名、布局或使用数据。

- 布局、设置、规则、快照和规则历史保存在配置的数据目录；日志保存在独立的日志目录。
- 默认数据目录为 `%LocalAppData%\ZDesk`，日志目录为 `%LocalAppData%\ZDesk\logs`，可在“设置 → 存储”中修改。
- 文件夹映射使用当前 Windows 用户已有的文件系统权限，不会绕过权限检查。
- 诊断包只在用户主动创建时生成；布局路径和规则路径会在写入诊断包前脱敏。
- 日志最多保留 14 个日期文件，可能包含操作类别、错误消息和部分文件名。
- 更新检查在正式 HTTPS manifest 源配置前保持关闭。

分享诊断包前仍应检查其中是否包含不希望公开的应用相关文件名。
