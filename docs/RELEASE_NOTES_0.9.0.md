# Z-Desk 0.9.0 发布说明

## 主要内容

- 普通布局、文件夹映射布局和组合页签布局。
- 文件拖放、Shell 原生菜单、重命名、属性、回收站删除和 QuickLook 兼容。
- 双击桌面空白隐藏、快捷键置顶、自动折叠和多显示器拖动。
- 默认自动归类规则与首次启动组合布局。
- 布局备份、快照、规则执行、数据迁移和异常退出图标恢复。
- 单文件便携版。
- 布局普通选择不再打开或跳转 Explorer；映射文件可通过 QuickLook Provider 直接预览。
- 文件重命名、复制、移动、粘贴和删除改用 Windows `IFileOperation`，原生右键菜单支持扩展子菜单和跨目录多选。
- 修复自动归类规则页初始化递归刷新和“应用”按钮误点亮；大量规则使用回收式虚拟化。
- 文件变更按项目增删/替换，不再因单个文件改名或新增重建整个布局。

## 平台说明

- 发布目标为 Windows x64。
- Windows 10 22H2 支持核心功能。
- Windows 11 第一层桌面右键菜单需要独立的签名 MSIX/COM 扩展，便携版不会自动部署。

## 已知限制

- 当前发布包未使用正式代码签名证书，首次运行可能出现 SmartScreen 提示。
- Explorer 图标恢复、多显示器 DPI、QuickLook 实际安装、回收站取消、跨应用拖放和扩展菜单仍需要目标系统人工验收。
- Windows 10 已结束微软常规支持，项目提供兼容性支持，不代表操作系统仍受微软支持。
