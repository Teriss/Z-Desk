# Z-Desk UI 设计规范

本规范是新增和修改界面的验收基线。设置中心及其子界面必须复用同一套视觉语言，不得退回 WPF 系统默认控件外观。

## 1. 信息架构

- 设置中心固定使用左侧单列导航、右侧内容区；点击导航只切换页面，不改变导航顺序。
- 页面标题与说明置于内容顶部，配置按主题放入卡片。删除无操作价值的装饰、重复标题和大面积禁用区域。
- 模式选择使用“标题 + 说明”的整行卡片，整行可点击；不得使用裸露的默认 `RadioButton`。
- “全部布局”等总开关启用后，隐藏不再适用的子选项，不保留灰色大块占位。

## 2. 色彩与层级

| 用途 | 颜色 |
| --- | --- |
| 窗口背景 | `#1E1F26` |
| 标题栏 | `#171820` |
| 左侧导航 | `#1A1B22` |
| 卡片 | `#202129` |
| 输入/列表表面 | `#1B1D24` / `#24262E` |
| 常规边框 | `#353741` / `#40434F` |
| 主文字 | `#F3F4F8` |
| 辅助文字 | `#B5B6C1` |
| 强调色 | `#4A82D8` |

- 深色页面严禁出现系统默认白底列表、下拉框、表格或输入框。
- 文字与背景必须保持清晰对比；禁用态可以降低透明度，但仍应能辨认内容和当前值。
- 选中态用强调色边框或深蓝表面表达，不只依赖细小图标或低对比文字。

## 3. 字号与间距

- 页面标题：24 px，`SemiBold`。
- 区块标题：13–17 px，`SemiBold`。
- 正文与控件：13 px。
- 辅助说明：11 px，使用辅助文字色。
- 页面内容边距：水平 30–44 px，垂直 24–30 px。
- 卡片内边距：18 px；卡片间距：18–22 px；同组控件间距：8–10 px。
- 表格主要信息列使用 `*` 填满可用宽度，避免右侧无意义空白；高度按实际编辑任务分配。

## 4. 控件要求

- `RadioButton`、`CheckBox`、`ComboBox`、`ListBox`、`DataGrid`、`ScrollBar` 必须使用项目主题模板，禁止依赖操作系统默认模板。
- 所有可交互控件必须定义正常、悬停、按下/选中、禁用和键盘焦点状态。
- 图标使用项目内 WPF `Path/Geometry`；不得依赖仅 Win11 存在的图标字体。
- 滚动条轨道和滑块必须有明显明度差；隐藏滚动条时不得禁用鼠标滚轮。
- 列表选择不能触发重排。拖动排序时直接移动原项目，跨越相邻项目后才交换，并提供平滑位移动画。
- 表单不可把“类型限定”等实现细节直接暴露成难以理解的勾选项；优先通过预设和字段语义表达。

## 5. 实现约束

- 新页面先复用 `Resources/SettingsTheme.xaml` 和现有窗口资源；需要新模式时先扩展公共资源，再应用到页面。
- 不得在业务页面临时使用默认控件拼出一套独立风格。新增视觉常量应进入主题资源，并使用语义化键名。
- 界面变更不得改变数据顺序、隐式提交设置或阻塞设置窗口之外的布局交互。

## 6. UI 验收清单

每次 UI 变更至少检查：

- Windows 10 与 Windows 11 字体、图标是否完整。
- 100%、125%、150% DPI 下是否存在裁切、重叠和异常留白。
- 正常、悬停、按下、选中、禁用、空列表和滚动状态是否清晰。
- 深色表面是否出现默认白底控件，文字和选中值是否可读。
- 窗口缩到最小允许尺寸后，主要操作是否仍可访问。
- 设置窗口打开期间，桌面布局是否仍能拖动、编辑和实时同步。
