# 用户指南

## 运行、升级与清理

- 便携版直接运行 `ZDesk.exe`，不会写入安装目录外的程序文件。
- 升级时替换旧的 `ZDesk.exe` 即可，建议先退出正在运行的 Z-Desk。
- 清理程序文件只需删除 `ZDesk.exe`；布局、设置和备份默认保留在 `%LocalAppData%\\ZDesk`，如需彻底清理请先在设置中备份后手动删除该目录。
- 从旧版本升级前建议复制 `layout.json` 和 `layout.backup.json`；新版本会尝试迁移旧数据并保留备份。

## 常见问题

- **桌面图标没有恢复**：退出 Z-Desk 后等待 Explorer 刷新；若仍未恢复，重新启动 Explorer 或重新登录 Windows。
- **快捷方式图标为空**：`.lnk` 和 Steam 等 `.url` 会读取 Shell 图标；图标源文件不可用时会回退为系统默认图标。
- **文件操作失败**：确认当前用户对目标路径有权限，网络盘、受保护目录和正在使用的文件可能被 Windows 拒绝。
- **QuickLook 不可用**：确认对应 Provider 已安装并在系统中可运行；映射项目不会改变真实文件路径。
- **Windows 10/11 差异**：核心布局和文件操作支持 Windows 10 22H2；Windows 11 第一层桌面右键菜单需要单独安装并信任 MSIX/COM 扩展。
- **发布包**：项目仅提供便携版 `ZDesk.exe`，不会自动部署 Windows 11 第一层桌面菜单扩展。

## 基本操作

- Z-Desk 启动后直接进入桌面布局模式，没有画板模式。
- 双击托盘图标或再次启动程序打开设置。
- 双击 Explorer 桌面空白区域隐藏或显示全部布局。
- 按设置中录制的全局快捷键切换全部布局置顶；再次按下恢复到普通应用之后的桌面层。
- 拖动布局标题栏移动布局，拖动右下角调整大小。
- 点击锁定按钮锁定布局位置和尺寸。
- 布局重叠时，最近交互的布局显示在其他布局前面。

## 文件与映射布局

- 文件夹映射布局直接显示指定文件夹内容。
- 从 Explorer 拖入或拖出布局时执行真实文件移动，不代表复制。
- 在同一布局内拖动只调整显示顺序，不移动文件。
- 右键文件使用 Windows 原生 Shell 菜单；支持打开、重命名、属性和其他系统扩展。
- `Delete` 将选中文件移入 Windows 回收站。
- 文件冲突不会静默覆盖，系统会生成 `(2)` 等唯一名称。

## 组合布局

- 右键布局空白区、标题或页签，选择“新建布局 → 普通布局/映射布局”。
- 将布局拖到另一个布局上可合并为页签布局。
- 从页签拖出可拆分为独立布局；拖回原宿主会恢复原页签位置。
- 组合布局的自动折叠设置由宿主共享，拆分后由新布局继承。

## 设置与规则

- 设置窗口可以保持打开，同时继续操作布局。
- 外观参数会实时预览；“应用”保存但不关闭窗口，“确定”保存并关闭。
- 自动归类规则按列表顺序匹配，首次匹配的规则获得文件。
- “立即重新归类桌面”只改变布局归属，不移动真实文件。
- “存储”页可以迁移数据目录和日志目录；迁移会保留旧目录备份。

## 恢复与诊断

- 主状态文件：`layout.json`；保存前保留 `layout.backup.json`。
- 设置中的恢复功能可以载入上一份有效布局，不修改真实文件。
- 应用启动后会隐藏 Explorer 桌面图标层；正常退出或异常 watchdog 会恢复图标层。
- 诊断包只在用户主动创建时生成，包含脱敏布局数据和当前日志。
